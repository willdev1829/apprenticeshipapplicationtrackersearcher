Application Searcher:
- This program is used to search for apprenticeships to apply for using the government apprenticeships pages.
How it works:
- This program fetches vacancies from government apprenticeship page.
- Then, these are stored and filtered in my database.
- Then, The relevant vacancies are displayed in a dashboard on my computer.
- Also, the top 5 are sent as a push notification to my phone.
- This process is scheduled to run daily using GitHub Actions.
- Also, on the dashboard application progress can be tracked.
Limitations:
- Only currently works for government apprenticeships service.
Technologies:
- Python
- SQL(SQLite 3)
- REST API
- Streamlit
